# Ledger cross-TF adapter wired to structural review gate

The research-only ledger adapter now accepts full `event/source_bar/review` bundles rather than caller assertions such as `verified_at` or `reviewed_formation_event_id`. For each visible ledger level it validates symbol, timeframe, formation event ID, price and tick against the bundle, and invokes `verify_reviewed_extremum()` before creating a qualified cross-TF view. Rejected review decisions and arbitrary qualification flags cannot pass this path. Future reviews are excluded at the requested as-of timestamp. D1/W1 candle overlap remains permitted as level-strengthening evidence within inclusive symmetric luft. Canonical ledger primary types, states and evidence lists remain unchanged.

Added regression for a forged `structural_qualification` flag with rejected review; updated existing adapter tests to full source bundles. **Test execution status: pending for these exact commits.** The gate validates supplied records and chronology; it does not cryptographically authenticate reviewers or prove the semantic correctness of manual structural classification. No live-trading promotion or production changes.
