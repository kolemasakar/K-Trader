# Збір та аналіз статистики

## Статус і правила використання
**Статус:** узагальнення, частина 1; навчальні визначення й дослідницькі гіпотези, НЕ автоматично затверджені торгові правила. Історичні рекомендації звіряти з актуальним кодом, конфігурацією, causal replay і незалежною перевіркою. Не змінювати production чи ризикові ліміти на підставі цього документа.

**Походження:** історичні матеріали `01_levels_rules.pdf`, `02_ATR_and_range.pdf`, `03_money_management.pdf`, `04_position_sizing.pdf`, `K_Trader_KB_VSA_ATR_SysInstrAddition1.md`; пріоритети `00_KNOWLEDGE_PRIORITY.md`; результати офлайнових досліджень BTC H1 та Phase 11G, відомі станом на 28.09.2026. Точні історичні числа не переносити між інструментами без повторного тесту.

## Узагальнення
- Для кожного OHLCV запису: провайдер, інструмент/контракт, UTC open/close, таймфрейм, якість, пропуски, дублі, хеш, версія набору. Для кожного сигналу: causal snapshot, версія алгоритму, параметри, рішення, причина відхилення.
- Вимірювати до побудови стратегії: future returns 15m/30m/1h/2h/4h/8h/12h/24h, MFE/MAE, time-to-MFE/MAE, path shape, directional efficiency, режими ATR/обсягу/сесії.
- Після формування стратегії: кількість подій, fill rate, net R, expectancy, медіана, drawdown, turnover, витрати, кластерні довірчі інтервали, стабільність за часом, активом і напрямом.
- Розділити discovery/development, walk-forward, заздалегідь заморожений новий OOS і prospective; раніше переглянутий holdout більше не незалежний. Забезпечити embargo й week-cluster bootstrap для залежних подій.
- Зафіксовані BTC H1: річний набір 8760 барів і 1124 події; окремий попередній рік теж використовувався для перевірок. Нові перевірки потребують перевірки фактичної незалежності від усіх попередніх гіпотез.
- Висновки позначати: визначення / гіпотеза / досліджено / не підтверджено / підтверджено незалежно; публікувати метод, дані, SHA256, код і обмеження.
## Додатки №3 — додаткові тести
Перевіряти внесок бенчмарка і відносної сили через ablation (стратегія без/із PRE-MKT), лише на однакових подіях і з доступними на той момент даними. Вимірювати нестабільність кореляції, часові зсуви, розподіл за режимами, витрати, незалежні часові блоки; навчальні приклади не є backtest. Не рахувати повторний 11-пунктний чекліст окремим незалежним джерелом ознак.
