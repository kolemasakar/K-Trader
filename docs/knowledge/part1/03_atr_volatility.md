## Узагальнення
- True Range = max(H−L, |H−C_prev|, |L−C_prev|). ATR — згладжене або усереднене TR; зазначати метод, період, timeframe та одиниці. Історичний «ATR5D» з очищених денних High−Low — інша метрика, її не змішувати зі стандартним ATR(TR).
- Розділяти статистичний потенціал ходу (ATR), реалізований рух за сесію та технічний простір до наступного рівня. «Технічний ATR» з історичного джерела — описова відстань між бар'єрами, не стандартний ATR.
- ATR впливає на масштаб стопа, розмір позиції, ширину зони, мінімальний рух після комісій, час до цілі та придатність горизонту. Режими compression/expansion оцінювати окремо.
- Історичні пороги ATR_used 40/60/80/100% — лише гіпотези; вони не універсальні hard gates.
- **Аудит BTC H1:** у дослідженні фільтр ATR відхилив 58.32% та 63.90% TR за два річні періоди, зафіксовано 266 і 257 серій по п'ять відхилень. Можливе застигання бази на попередньому режимі. Порівняти accepted-only baseline, календарне робастне вікно й механізм regime reset; не змінювати пороги без тесту.
- Чутливість: однакові цінові події, різні ATR-оцінювачі, частка відхилень, стабільність зон, ефективність після витрат; відокремити дослідження від production.
