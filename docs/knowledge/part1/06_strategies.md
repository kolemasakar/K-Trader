# Стратегії та статус доказів

## Статус і правила використання
**Статус:** узагальнення, частина 1; навчальні визначення й дослідницькі гіпотези, НЕ автоматично затверджені торгові правила. Історичні рекомендації звіряти з актуальним кодом, конфігурацією, causal replay і незалежною перевіркою. Не змінювати production чи ризикові ліміти на підставі цього документа.

**Походження:** історичні матеріали `01_levels_rules.pdf`, `02_ATR_and_range.pdf`, `03_money_management.pdf`, `04_position_sizing.pdf`, `K_Trader_KB_VSA_ATR_SysInstrAddition1.md`; пріоритети `00_KNOWLEDGE_PRIORITY.md`; результати офлайнових досліджень BTC H1 та Phase 11G, відомі станом на 28.09.2026. Точні історичні числа не переносити між інструментами без повторного тесту.

## Узагальнення
- Дослідницька стратегія = чіткий стан ринку + тригер + causal-правила входу/виходу + інвалідація + управління ризиком + перевірка за режимами.
- Сімейства: трендове продовження після корекції; breakout/retest; відбій від HTF-рівня; sweep/reclaim; FVG retest; VSA-контекст; комбіновані HTF/LTF.
- Phase 11G S1–S6: історичний набір 1334 подій; S6 H1 20-bar breakout + EMA50 + близькість D1/weekly level, але попередній holdout уже аналізувався.
- Самостійні VSA/SMC і комбіновані фільтри не дали відтворюваного доказу стійкої переваги; регресійні дослідження показали нестабільний додатковий внесок SMC після VSA.
- BTC H1 1124 embargo-filtered патерн-подій за рік: повторюваність форми й дзеркальні рухи спостерігалися, стабільного позитивного net-R обома періодами не показано.
- Порядок дослідження: спершу асиметрія future return/MFE/MAE/path shape; потім параметризація стратегії; потім walk-forward, новий незалежний OOS і prospective. Не оголошувати «робочою» за результатами posthoc відбору.
